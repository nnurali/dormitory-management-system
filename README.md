# Dormitory Management System
Бұл веб-қосымша студенттерге университет жатақханасының бос бөлмелерін қарап шығуға, орналасуға өтінім беруге және комендантқа өтінімдерді басқаруға көмектеседі.

## Мақсаты
Жатақханаға орналасу үдерісін автоматтандыру және ашықтығын қамтамасыз ету.

## Пайдаланушылар
- Студент
- Комендант

## Талаптар
1. Студент жүйеге жеке логин және пароль арқылы кіреді.
2. Студент қолжетімді бос бөлмелер тізімін қарап шығады.
3. Студент таңдалған бөлмеге орналасу үшін электронды өтінім береді.
4. Студент өтінімінің ағымдағы статусын бақылайды.
5. Комендант жүйеге кіріп, келіп түскен жаңа өтінімдерді көреді.
6. Комендант өтінімді қарап шығып, мақұлдайды немесе қабылдамайды.
7. Жүйе өтінім статусы өзгерген кезде студентке хабарлама жібереді.
8. Жүйе бос орындардың санын автоматты түрде жаңартып отырады.
